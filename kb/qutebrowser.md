# Qutebrowser quick reference

## Navigation
hjkl        left, down, up, right
+,-         zoom
o           new url
go          edit current url
O           new tab
J           next tab
K           prev tab
Alt-n       tab n
d           close tab
u           undo close tab
H           back
L           forwards
f           show hints
/           search in page
n           next item
N           prev item
