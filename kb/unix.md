# General unix quick reference

Ctrl+Alt+j      Switch to vi mode in readline program
!x              Execute last command matching x pattern
Ctrl-r          Reverse search command history
a | b           pipe from stdout a to stdin b
a > b           redirect stdout a to file b (overwrite)
a >> b          redirect stdout a to file b (append)
a < b           redirect file b to stdin of a
;               command separator
a && b          run b only if a succeeds
a || b          run b only if a fails
a &             run a in bg
