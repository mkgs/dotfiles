# ranger quick reference

## Movement
j, k        down, up
h           parent directory
l           subdirectory
gg          top of list
G           bottom of list
J           half page down
K           half page up
H           history back
L           history forward
~           switch view

## Operation
Enter       open
r           open with
o           sort order
z           toggle settings
zh          view hidden files
cw          rename file
yy          copy
dd          cut
pp          paste
/           search
n           next match
N           prev math
<delete>    delete
!           execute shell command

## Tabs
Ctrl-n      new tab
Ctrl-w      close tab
tab         next tab
shift+tab   prev tab
